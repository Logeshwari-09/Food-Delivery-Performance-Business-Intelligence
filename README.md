# 🍔 Food Delivery Performance & Business Intelligence
### An End-to-End Data Analytics Project

## 📌 Project Overview

Food Delivery Analytics is an end-to-end data analytics project
developed to analyze food delivery operations, customer behavior,
restaurant performance, sales trends, and delivery efficiency.

This project combines Microsoft Excel, Python, MySQL, and Power BI
to transform raw data into meaningful business insights through
data cleaning, SQL analysis, data visualization, and an interactive
dashboard.

## 🎯 Project Objectives

- Clean and prepare raw datasets.
- Analyze food delivery data using Python.
- Store and manage relational data using MySQL.
- Analyze sales, customers, restaurants, and deliveries.
- Create calculated measures using DAX in Power BI.
- Develop an interactive dashboard for business analysis.

## 📂 Dataset Description

The project contains seven relational datasets:

1. Customers
2. Restaurants
3. Menu
4. Orders
5. OrderDetails
6. Payments
7. Deliveries

These datasets cover customer information, restaurant details,
menu items, orders, payments, and delivery performance.

## 🧹 1. Data Cleaning Using Excel

Excel was used to prepare the datasets before analysis.

Tasks included:
- Inspecting the datasets.
- Checking missing values.
- Identifying data inconsistencies.
- Cleaning and organizing columns.
- Preparing datasets for analysis and database import.

## 🐍 2. Data Analysis Using Python

Python was used to explore the datasets and visualize patterns.

Libraries:
- Pandas
- NumPy
- Matplotlib

Tasks included:
- Loading datasets into DataFrames.
- Inspecting data types using `dtypes`.
- Checking dataset structure and data quality.
- Performing data analysis using Pandas.
- Creating charts using Matplotlib.
- Exploring trends and patterns in the data.

## 🗄️ 3. SQL Analysis Using MySQL

MySQL was used to create and query the relational database.

Database name: `food_delivery_analytics`

SQL concepts used:
- Database and table operations.
- SELECT, WHERE, and ORDER BY.
- Aggregate functions.
- GROUP BY and HAVING.
- JOIN operations.
- Subqueries.
- Common Table Expressions (CTEs).
- Window functions.

The analysis focuses on customer activity, restaurant sales,
menu performance, orders, payments, and delivery operations.

## 📊 4. Dashboard Development Using Power BI

Power BI was used to build an interactive dashboard.

### Key Performance Indicators (KPIs)

- Total Orders
- Gross Sales
- Total Customers
- Average Order Value
- Cancellation Rate

### Dashboard Visualizations

- Monthly Sales Trends
- Top Restaurants by Sales
- Best-Selling Menu Items
- Customer Membership Distribution
- Delivery Performance
- City-Wise Item Sales
- Payment Analysis

### DAX and Calculations

DAX measures were created to calculate business metrics such as
gross sales, total orders, average order value, and cancellation rate.

Interactive slicers allow users to explore the dashboard by
different categories, including order date, city, cuisine,
order status, and payment method.

## 🔍 Business Questions

This project explores questions such as:

- Which menu items are sold the most?
- How do sales change over time?
- What is the order cancellation rate?
- How are customers distributed across cities?
- Which payment methods are used?
